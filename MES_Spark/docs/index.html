Adjuntar archivos

PDF, STEP, STP o STL · Hasta 200 MiB por archivo. Un adjunto principal por OT/POS. Elegí el original desde la carpeta compartida. Al guardar la hoja de ruta se envía solamente su referencia a Firebase, no el contenido. No se crea una copia persistente en el navegador. En otra PC o después de recargar deberás seleccionar el original nuevamente; se comprobará su revisión por contenido. Modelos complejos pueden superar la memoria del equipo.

Planos de este dispositivo

SharePoint: elegí el archivo desde una carpeta sincronizada o descargalo primero. Las copias no se actualizan automáticamente.

El respaldo contiene planos, no las órdenes de Firebase. Usá siempre la misma dirección, navegador y perfil para encontrar tus copias.
